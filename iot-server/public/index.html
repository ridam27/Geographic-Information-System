INFO
About This Unit

System

This panel talks to an ESP32 board over a WebSocket bridge run by a small Express server. The board reports flame, sound, soil, and rain-gauge/pump readings continuously; the panel sends LED, disco, and servo commands over plain HTTP.

When the connection dot in the top bar is dark, the ESP32 hasn't registered itself with the server yet — commands will fail until it reconnects.

Endpoints in use

  • GET /led/:id/:state  set LED1–LED3 on or off
  • GET /disco/on  / /disco/off  disco sweep
  • GET /servo/:angle  set shaft position, 0–180
  • GET /status  connection state
  • GET /flame  full sensor + detection state (tank level, volume, rainfall mm, and pump state included)
ESP32 Offline — command not sent
