System & API Specifications

System Architecture ARCHITECTURE

The Geolith IoT Server bridges hardware telemetry from the ESP32 microcontroller into the unified GIS Portal via dual-layer WebSocket and MQTT broker communication pipelines.

Method Endpoint Route Description
GET /led/:id/:state Actuates digital LED channels 1, 2, or 3 (state: ON / OFF)
GET /disco/on Initiates automatic 3-channel sequencing pattern
GET /disco/off Terminates LED sequencer pattern
GET /servo/:angle Commands PWM servo shaft positioning (0 to 180 degrees)
GET /status Returns connection heartbeat and device registry
GET /flame Returns full telemetry state snapshot (sensors, pump, tank depth)
GET /health Server and MQTT broker health check diagnostic
ESP32 Offline — command not sent
